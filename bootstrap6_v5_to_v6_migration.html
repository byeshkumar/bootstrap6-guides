Migration Guide: v5 to v6

Every class rename, data-attribute change, markup restructure, JavaScript and Sass change you need to move a v5 project to Bootstrap 6.

Written against Bootstrap 6.0.0-alpha.1. Alpha releases may still change; verify against the installed package before shipping.

Version note: Bootstrap 6 is alpha. This page documents the official v6 migration changes and uses the 6.0.0-alpha.1 CDN. Since v6 adds new features alongside these changes, treat the "new components" section as optional reading rather than required migration work.

Migration checklist

Work through these in order. After each step, search the codebase for remaining v5 patterns before moving on.

  1. Update dependencies and build setup
  2. Rename CSS classes and data attributes
  3. Restructure component HTML
  4. Update JavaScript
  5. Update Sass
  6. Verify and test
The five changes that break most projects
  • Breakpoint and state modifiers moved to a prefix with a colon: col-md-6 → md:col-6.
  • Modal, Offcanvas, and Dropdown were renamed to Dialog, Drawer, and Menu.
  • btn-primary style variants became variant + theme token: btn-solid theme-primary.
  • The JavaScript bundle is ESM-only: window.bootstrap is gone.
  • Sass files, variables, and the spacer scale changed; @import must become @use.

1Dependencies & build

Itemv5v6
Packagebootstrap@5.xbootstrap@6.0.0-alpha.1
Positioning engine@popperjs/core@floating-ui/dom
Datepicker peer—vanilla-calendar-pro
TypeScript types@types/bootstrapBundled (source is TypeScript; remove @types/bootstrap)
Sass imports@import@use (Node Sass is no longer supported)

The bundled build includes Floating UI and Vanilla Calendar Pro. The standalone bootstrap.js leaves both peers external — loading it directly in a browser needs an import map.

Sass entry point
// v5
@import "bootstrap/scss/bootstrap";

// v6
@use "bootstrap/scss/bootstrap";

// v6 with overrides — customize CSS tokens through the token maps
@use "bootstrap/scss/bootstrap" with (
  $root-tokens: (
    --spacer: 1rem,
  )
);

Customize with $root-tokens and each component's $*-tokens map instead of legacy Sass scalars. Token names are written unprefixed in Sass (--spacer); the dist/CDN build adds the --bs- prefix via PostCSS.

2Responsive & state prefix syntax

Breakpoints and pseudo-states moved from an infix or suffix to a prefix followed by a colon. xxl is now 2xl.

.{class}-{bp}-{value} becomes .{bp}:{class}-{value}, and .{class}-{bp} becomes .{bp}:{class}.

.col-md-6.md:col-6
.row-cols-md-3.md:row-cols-3
.offset-md-2.md:offset-2
.g-md-3, .gx-md-3.md:g-3, .md:gx-3
.g-col-md-4.md:g-col-4
.container-sm.sm:container
.navbar-expand-md.md:navbar-expand
.offcanvas-md.md:drawer
.table-responsive-md.md:table-responsive

Container queries: the prefix does not say which query type is used. Stacks, CSS Grid columns, navbar expansion, horizontal list groups, card groups, and stacked tables use container queries — add the query container each component's docs require.

4Variants become theme tokens

Per-color classes are replaced by a variant class composed with a .theme-* class on the same element. Built-in theme keys are primary, accent, success, danger, warning, info, inverse, and secondary.

v5v6
.btn-primaryclass="btn-solid theme-primary"
.btn-outline-primaryclass="btn-outline theme-primary"
.alert-primaryclass="alert theme-primary"
.badge.bg-primaryclass="badge theme-primary"

New button variants: .btn-solid, .btn-outline, .btn-subtle, .btn-text, .btn-styled, .btn-link.

Button markup (v6)
<button type="button" class="btn btn-solid theme-primary">Save</button>
<button type="button" class="btn btn-outline theme-secondary">Cancel</button>

Use .theme-reset on a nested subtree to drop inherited --theme-* tokens. There are no .theme-light or .theme-dark classes — review v5 light/dark variants manually and use neutral surfaces, color modes, or .theme-inverse.

6Type and spacing scales

The numeric font-size scale became t-shirt sizes, ascending: xs sm md lg xl 2xl 3xl 4xl 5xl 6xl. The rem values below are the v5 sizes, shown only to match each class.

v5v6
.fs-1 (2.5rem).fs-4xl
.fs-2 (2rem).fs-3xl
.fs-3 (1.75rem).fs-2xl
.fs-4 (1.5rem).fs-xl
.fs-5 (1.25rem).fs-lg
.fs-6 (1rem).fs-md

In v6, lg and larger are fluid clamp() values that scale with the viewport; xs, sm, and md stay fixed. Sizes keep the relative scale rather than matching v5 exactly.

Spacer keys 2–5 changed values. To keep v5 spacing, shift keys up.

Negative margins are limited to .ms--1, .ms--2, .me--1, .me--2. The v5 .m*-n* classes (.mt-n1, .ms-n3) are gone — use these or a custom style.

7Markup restructure

Dialog (was Modal)

Remove the .modal-dialog and .modal-content wrappers and use a single native <dialog>. The backdrop is now native ::backdrop.

v5
<div class="modal" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Title</h5>
        <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">Content</div>
    </div>
  </div>
</div>
v6
<dialog class="dialog" id="exampleDialog">
  <div class="dialog-header">
    <h5 class="dialog-title">Title</h5>
    <button type="button" class="btn-close" data-bs-dismiss="dialog" aria-label="Close"></button>
  </div>
  <div class="dialog-body">Content</div>
  <div class="dialog-footer">
    <button class="btn-solid theme-secondary" data-bs-dismiss="dialog">Close</button>
  </div>
</dialog>

Drawer (was Offcanvas)

Use a native <dialog> element. Renaming a <div class="drawer"> alone does not work.

<!-- v5 -->
<div class="offcanvas offcanvas-start" id="menu">...</div>

<!-- v6 -->
<dialog class="drawer drawer-start" id="menu">...</dialog>

For responsive navbars, change data-bs-toggle="collapse" to data-bs-toggle="drawer". Replace .collapse.navbar-collapse with a <dialog class="drawer"> containing .drawer-header and .drawer-body, rename .navbar-expand-md to .md:navbar-expand, and remove .navbar-light / .navbar-dark.

Accordion

Collapse JS is replaced by native <details>/<summary>. The name attribute creates exclusive groups (replacing data-bs-parent). Remove .accordion-button and .accordion-collapse. New modifiers: .accordion-sm for compact spacing and .accordion-gap to space items as separate rounded cards.

<div class="accordion">
  <details class="accordion-item" name="myAccordion" open>
    <summary class="accordion-header">
      Item 1
      <svg class="accordion-icon" xmlns="http://www.w3.org/2000/svg" viewBox="0 0 16 16"
           fill="none" stroke="currentColor" stroke-linecap="round" stroke-linejoin="round">
        <path d="m2 5 6 6 6-6"/>
      </svg>
    </summary>
    <div class="accordion-body">Content</div>
  </details>
</div>

Menu (was Dropdown)

Remove the .dropdown wrapper and .dropdown-toggle, flatten <ul><li><a> to <div><a>. The toggle and the .menu are siblings.

<!-- v5 -->
<div class="dropdown">
  <button class="btn dropdown-toggle" data-bs-toggle="dropdown">Menu</button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">Action</a></li>
    <li><hr class="dropdown-divider"></li>
    <li><a class="dropdown-item" href="#">Other</a></li>
  </ul>
</div>

<!-- v6 -->
<button class="btn-solid theme-secondary" data-bs-toggle="menu">Menu</button>
<div class="menu">
  <a class="menu-item" href="#">Action</a>
  <hr class="menu-divider">
  <a class="menu-item" href="#">Other</a>
</div>

Checkbox, radio, and switch

Apply .check directly to the <input> — no wrapper and no inline SVG, the mark is a CSS mask on ::before. Radios use .radio; switches keep a .switch wrapper around the input.

<!-- v5 -->
<div class="form-check">
  <input class="form-check-input" type="checkbox" id="check1">
  <label class="form-check-label" for="check1">Check me</label>
</div>

<!-- v6 checkbox -->
<div class="form-field">
  <input type="checkbox" id="check1" class="check">
  <label for="check1">Check me</label>
</div>

<!-- v6 radio -->
<div class="form-field">
  <input type="radio" id="radio1" class="radio">
  <label for="radio1">Pick me</label>
</div>

<!-- v6 switch -->
<div class="form-field">
  <div class="switch">
    <input type="checkbox" id="switch1" role="switch" switch>
  </div>
  <label for="switch1">Toggle me</label>
</div>

Toggle buttons

The input is now nested inside the label. .btn-check goes on the label, and no id/for pairing is needed.

<!-- v5 -->
<input type="checkbox" class="btn-check" id="toggle1" autocomplete="off">
<label class="btn btn-outline-primary" for="toggle1">Toggle</label>

<!-- v6 -->
<label class="btn-check btn-solid theme-primary">
  <input type="checkbox" autocomplete="off">
  Toggle
</label>

Range

.form-range is now a wrapper and a JavaScript hook. Move the class off the input and add .form-range-input to the input.

<!-- v5 -->
<input type="range" class="form-range">

<!-- v6 -->
<div class="form-range">
  <input type="range" class="form-range-input">
</div>

Breadcrumbs

Add .breadcrumb-link to links and empty .breadcrumb-divider separators (replacing the ::before pseudo-elements). An empty divider renders a default chevron via a CSS mask. The default bottom margin is gone.

<!-- v5 -->
<ol class="breadcrumb">
  <li class="breadcrumb-item"><a href="#">Home</a></li>
  <li class="breadcrumb-item active">Library</li>
</ol>

<!-- v6 -->
<ol class="breadcrumb">
  <li class="breadcrumb-item"><a class="breadcrumb-link" href="#">Home</a></li>
  <li class="breadcrumb-divider"></li>
  <li class="breadcrumb-item"><a class="breadcrumb-link active" href="#">Library</a></li>
</ol>

Cards

Card markup changed in several smaller ways. Review custom card CSS against these rules.

  • .card owns the background, outer border, radius, shadow, and height; headers and footers only draw their divider border.
  • .card-body is optional and is now a flex column that removes direct-child block margins and uses --card-body-gap. Add .flex-row for a horizontal body.
  • Keep .list-group-flush on list groups inside cards. Do not add .card-list — it does not exist.
  • .card-title and .card-text no longer add styles; keep them only as project hooks. .card-subtitle still reduces the gap above it.
  • .card-link is removed — use normal links with flex or gap utilities.
  • Use .card-row for horizontal cards, and .card-subtle or .card-translucent for the new variants.
  • Card groups now use a container query — add .contains-inline to a parent or the cards stay stacked.

Close button

The markup does not change — .btn-close stays empty. Do not add a child SVG or the icon renders twice. Internally v6 draws it with a CSS mask over background-color: currentcolor, so the button inherits the current text color.

<!-- identical in v5 and v6 -->
<button type="button" class="btn-close" aria-label="Close"></button>

Because the icon uses currentcolor, .btn-close-white is removed. To get a light close button, set the text color — place it in a dark .theme-* context or add a .fg-* / color utility.

9JavaScript changes

All dist files are now ES modules. There are no UMD bundles and no window.bootstrap global.

<!-- v5 -->
<script src="bootstrap.bundle.min.js"></script>

<!-- v6 -->
<script type="module" src="bootstrap.bundle.min.js"></script>
// v5 — global namespace
const tooltip = bootstrap.Tooltip.getOrCreateInstance(el);

// v6 — explicit import
import { Tooltip } from './bootstrap.bundle.min.js';

const tooltip = Tooltip.getOrCreateInstance(el);

The data API still initializes automatically once you add type="module". Bundler imports such as import { X } from 'bootstrap' work as before.

Areav5v6
JS exportModal, Offcanvas, DropdownDialog, Drawer, Menu
Positioning@popperjs/core@floating-ui/dom
Config optionpopperConfigfloatingConfig (Tooltip, Popover, Menu)
TypeScript@types/bootstrapDeclarations ship with the package

Lifecycle methods return a promise. show(), hide(), toggle(), and close() now resolve when the transition ends, so you can await them instead of listening for shown.bs.* / hidden.bs.*. The events still fire.

// v6 — await the transition instead of listening for shown.bs.dialog
const dialog = new Dialog(el);
await dialog.show();

Hover and focus tooltips stay open while the pointer or focus is on the tip itself (WCAG 1.4.13). Press Escape or leave both the trigger and the tip to hide it. Popup datepickers close on outside interaction, on Escape, or when focus leaves the input and calendar.

Removed: jQuery support, bootstrap.esm.js / bootstrap.esm.min.js (use bootstrap.js), and js/index.umd.js.

Border radius scale

The $border-radius-* variables are gone. v6 uses a single base $radius: .5rem and a $radii map (keys 0–9), exposed as --radius-0–--radius-9 plus --radius-pill. .rounded-* now spans 0–9 with different values, so shift numbers up to keep the same roundness (.rounded-1 → .rounded-3, .rounded-3 → .rounded-5).

// $radius lives in _config.scss — configure that module before loading Bootstrap
@use "bootstrap/scss/config" with (
  $radius: .375rem // scales the whole map
);
@use "bootstrap/scss/bootstrap";

Removed with no replacement

  • $nested-kbd-font-weight, $enable-validation-icons, $enable-dark-mode (dark mode is always compiled)
  • $enable-caret, $caret-width, $caret-vertical-align, $caret-spacing and all caret mixins — add an icon to the toggle markup instead
  • $accordion-button-focus-border-color, $tooltip-arrow-color, $popover-arrow-color, $popover-arrow-outer-color
  • $alert-bg-scale, $alert-border-scale, $alert-color-scale, $list-group-item-bg-scale, $list-group-item-color-scale
  • $carousel-dark-indicator-active-bg, $carousel-dark-control-icon-filter, $dropdown-header-padding
  • All *-focus-box-shadow variables — use the focus-ring() mixin with --focus-ring-* custom properties
  • RFS mixins — use clamp() for responsive sizing; create-css-vars() mixin
  • muted, black-50, and white-50 from the text color utilities map

Utility API: the css-var, css-variable-name, and local-vars options were removed — use a property map and variables instead.

Theme maps merge: $theme-colors, $theme-bgs, $theme-fgs, $theme-borders, $badge-variants, and other global maps use defaults(). Pass only the keys you want through @use ... with (); set a key to null to drop it. Nested theme-color maps merge one level deep, so pass the whole sub-map to change one role.

Root tokens emit on :root, :host. Repeat :root overrides on :host if you use shadow DOM.

11Rebuilt components

Carousel — CSS scroll-snap

The markup and JS API are preserved, but several things changed.

  • ride → autoplay (boolean, opt-in). data-bs-ride="carousel" becomes data-bs-autoplay="true"; { ride: 'carousel' } becomes { autoplay: true }. Default is false, so a v5 carousel that auto-advanced now sits still.
  • Interacting with an autoplaying carousel now permanently stops it (WCAG 2.2.2).
  • wrap → ends: wrap: true → ends: "wrap" (or the new default "loop"); wrap: false → ends: "stop". Set via data-bs-ends. The touch option is removed.
  • Removed classes: .carousel-control-prev/next (compose a .btn-icon + data-bs-slide + .carousel-icon-prev/next), .carousel-caption, .carousel-dark (use data-bs-theme="dark"), .carousel-stacked (now the default), and the transitional .carousel-item-start/end/next/prev.
  • Overlaid controls now require .carousel-overlay. .carousel-control-prev-icon → .carousel-icon-prev (and -next).

ScrollSpy — IntersectionObserver

The data-bs-spy="scroll" markup and the activate.bs.scrollspy event are unchanged, but detection is driven by an activation line instead of scroll polling.

  • Removed the deprecated offset and method options.
  • Added topMargin (default 12%) — the everyday knob; use 96px to sit below a sticky navbar.
  • rootMargin is now an advanced override (default null); when set it wins over topMargin.
  • threshold default changed from [0.1, 0.5, 1] to [0].
  • With smoothScroll, clicking a link restores the URL hash and moves focus to the target once the scroll settles.
  • Target ids resolve with getElementById, so dots, colons, slashes, and percent-encoding work without escaping.

Collapse

  • Remove selectors and tests that depend on .collapsing — Collapse now toggles .show and uses native size interpolation.
  • Replace trigger .collapsed selectors with [aria-expanded="false"].
  • The toggle constructor option is removed — call show() or hide() when initialization must change state.

13Removed internals

Backdrop, focus trap, and scrollbar utilities are gone. util/backdrop.js, util/focustrap.js, and util/scrollbar.js were removed. Dialog and Drawer use the native <dialog> element, which provides the backdrop (::backdrop), the focus trap, and the inert top layer; the body scroll-lock is now CSS (:root.dialog-open). If you imported those utilities directly, they no longer exist.

CSS cascade layers. Component styles are wrapped in @layer (colors, theme, config, root, reboot, layout, content, forms, components, custom, helpers, utilities). Author CSS outside any layer now wins over Bootstrap regardless of source order — re-check overrides that relied on specificity or load order.

--bs-*-rgb variables removed. The $*-rgb Sass variables and --bs-*-rgb custom properties are gone. Replace rgba(var(--bs-primary-rgb), .5) with color-mix(in oklab, var(--bs-primary), transparent 50%) — or use the color directly.
