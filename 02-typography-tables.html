Bootstrap 6 · Subject Guide

Typography & Tables

Font-size scale and table styling patterns.

Version note: Bootstrap 6 is alpha. These guides use the 6.0.0-alpha.1 CDN. Some class names from your notes may require a custom build or project CSS.

1. Font-size scale

Use the font-size utility scale for headings, text, labels, and helper content.

fs-xs — extra small
fs-sm — small
fs-md — medium
fs-lg — large
fs-xl — extra large
fs-2xl — 2X large
fs-3xl — 3X large
fs-4xl — 4X large
fs-5xl — 5X large
fs-6xl — 6X large
Ready-to-use code
<p class="fs-xs">Helper text</p>
<p class="fs-md">Body text</p>
<h1 class="fs-4xl">Page heading</h1>
<div class="fs-6xl">Hero text</div>

2. Striped columns

Use table-striped-columns for alternate column shading rather than alternate row shading.
